Explanation of what the project is about:

This project is a modular, structured blueprint for a text-based 
RPG (Role-Playing Game) called "Legends of the Forgotten Realm." 
Written in Python, it breaks down the game into organized files 
that work together to manage characters, combat, game data, and
 player progress.
 The game operates as an interconnected machine. One file holds 
 the rules for characters, another acts as the database of items, 
 a third runs the battle engine, a fourth handles saving and loading,
  and a final central hub ties them all together into a playable loop.

Breakdown of Each Module

1. The Game Database (data.py)

This file acts as the game's official reference encyclopedia. It contains
 no functional gameplay logic, only static Python dictionaries and lists 
 that store:
• Character Classes: Starting health, mana, attack, and defense for the 
Warrior, Mage, Archer, and Assassin.
• Skill Trees: Special moves unlocked at higher levels, such as a Mage's
 Fireball or an Assassin's Instant Kill.
• Loot Tables: A massive list of weapons and armors separated by tier
 rarities (Common all the way to Legendary) along with random drop 
 percentages.
• World Map and Bosses: The names of different regions (like the
 Whispering Forest or Demon Realm) scaled by level, and the specific 
 high-powered bosses guarding every 10th milestone.

2. Character Blueprints (models.py)

This file defines the physical properties of the entities living 
inside the game:
• The Player: Sets up a level 1 hero. It features dynamic 
calculators (@property) that automatically add your weapon's 
attack power and your armor's defense value to your base stats
 in real-time. It also handles permanent stat increases when you
  gain enough EXP to trigger a level-up.
• The Enemy: A flexible generator that spawns standard minions whose 
stats scale based on your current region's difficulty, or overrides
 everything to build hardcoded, high-HP boss encounters.

3. The Battle Engine (combat.py)

This runs the active turn-based combat loop. When triggered, it locks
 the player and a monster in a sequence of turns until someone's HP
  hits zero. It handles player choices, like standard attacks (with 
  a random percentage roll for high-damage critical hits), spending mana
   on unlocked skills, drinking potions from an inventory pouch, 
   or taking a defensive stance to cut the enemy's next strike in half.

4. The Memory Core (system_save.py)

This file prevents players from losing their hard-earned progress.
• The Save function extracts the player's exact live status (current 
level, current gold, equipped gear, and potions) and writes it into a
 permanent text file called savegame.json.
• The Load function reads that JSON file upon request and completely 
rebuilds the player object back into memory so they can resume their 
quest seamlessly.

5. The Main Control Hub (main.py)

The nervous system of the project. It links all four previous files
 together using python import statements. It manages the primary title
  screen (New Game, Continue, Exit), handles player choices in the 
  main loop (Explore, Fight Boss, Visit Shop, Manage Gear), distributes
   gold, EXP, and random loot drops upon victory, and gracefully 
   closes the program via sys.exit() if you choose to quit or 
   suffer a game over.
